mlx-cluster¶

mlx-cluster provides fast graph algorithms for Apple's MLX framework: random walks, neighbor sampling, and sparse x dense matrix multiplication (SpMM) for GNN message passing. It is a C++ extension of MLX with Metal kernels, and the sampling and sparse backend of mlx-graphs.

pip install mlx-cluster

What's inside¶

  • Random walks: uniform walks (random_walk) and Node2Vec biased walks with p / q (rejection_sampling), on CPU and GPU.
  • Neighbor sampling: multi-hop GraphSAGE sampling (neighbor_sample), heterogeneous graphs (hetero_neighbor_sample) and meta-path walks (metapath_random_walk).
  • Fused message passing: SpMM with sum, mean, max and min, with gradients, in COO (spmm_coo) and load-balanced CSR (spmm_csr) formats.
  • Attention scores: multi-head dot products per edge (edge_scores) without per-edge feature arrays.
