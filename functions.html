mlx_cluster.rejection_sampling(rowptr: mlx.core.array, col: mlx.core.array, start: mlx.core.array, walk_length: int, p: float, q: float, *, key: object | None = None, max_attempts: int = 1000, stream: object | None = None) → tuple#

node2vec biased random walks (rejection sampling).

Having moved t -> v, the next node x is a neighbor of v chosen with weight 1/p if x == t, 1 if x is a neighbor of t, and 1/q otherwise. A node without neighbors keeps the walk in place (edge id -1).

Random numbers are generated inside the kernel from a counter-based generator seeded by key, so the CPU and GPU produce identical walks for the same key.

Parameters:

  • rowptr (mlx.core.array) -- CSR row pointers (int64).

  • col (mlx.core.array) -- CSR column indices (int64).

  • start (mlx.core.array) -- Start nodes (int64).

  • walk_length (int) -- Number of steps per walk.

  • p (float) -- Return parameter; larger values make returning to the previous node less likely.

  • q (float) -- In-out parameter; q > 1 keeps walks local (BFS-like), q < 1 pushes them outward (DFS-like).

  • key (mlx.core.array, optional) -- uint32 key with 2 elements, e.g. mx.random.key(0). If omitted, one is drawn from MLX's global RNG, so mx.random.seed makes walks reproducible.

  • max_attempts (int) -- Rejection-sampling cap per step. After this many rejections the last candidate is accepted. Default 1000.

  • stream (mlx.core.Stream | mlx.core.Device, optional) -- Where to run (mx.cpu or mx.gpu).

Returns:

(nodes, edges) of shapes [len(start), walk_length + 1] and [len(start), walk_length], both int64.

Return type:

tuple (mlx.core.array, mlx.core.array)

Heterogeneous graphs#

mlx_cluster.hetero_neighbor_sample(colptr_dict: Mapping[Tuple[str, str, str], array], row_dict: Mapping[Tuple[str, str, str], array], seed_dict: Mapping[str, array], num_neighbors: Sequence[int] | Mapping[Tuple[str, str, str], Sequence[int]], num_nodes_dict: Mapping[str, int] | None = None, replace: bool = False, directed: bool = True, seed: int | None = None) → HeteroSamplerOutput[source]#

Multi-hop neighbor sampling on a heterogeneous graph (GraphSAGE style).

For every edge type (src, rel, dst) and every hop, up to k incoming src neighbors are sampled for each dst node discovered at the previous hop (the seeds at hop 0).

Parameters:

  • colptr_dict (Mapping[Tuple[str, str, str], array]) -- CSC column pointers per edge type. For (src, rel, dst) this has num_dst_nodes + 1 int64 entries.

  • row_dict (Mapping[Tuple[str, str, str], array]) -- CSC row indices (source node of each edge, sorted by destination) per edge type, int64.

  • seed_dict (Mapping[str, array]) -- Seed node ids per node type. Must not contain duplicates.

  • num_neighbors (Union[Sequence[int], Mapping[Tuple[str, str, str], Sequence[int]]]) -- Fan-out per hop, e.g. [10, 5]. Either a single list used for every edge type, or a dict mapping each edge type to its own list. -1 takes all neighbors; 0 samples none. Shorter lists are padded with 0.

  • num_nodes_dict (Optional[Mapping[str, int]]) -- Optional number of nodes per node type (e.g. HeteroGraphData.num_nodes). Lets node types that only appear as a source use the faster dense id mapper.

  • replace (bool) -- Sample with replacement.

  • directed (bool) -- Only True is supported for heterogeneous graphs.

  • seed (Optional[int]) -- Seed for the sampler's RNG. If None, one is drawn from MLX's global RNG, so mx.random.seed(...) makes sampling reproducible.

Return type:

HeteroSamplerOutput

Returns:

HeteroSamplerOutput

Example:

out = hetero_neighbor_sample(
    colptr_dict={("author", "writes", "paper"): colptr},
    row_dict={("author", "writes", "paper"): row},
    seed_dict={"paper": mx.array([0, 1], dtype=mx.int64)},
    num_neighbors=[10, 5],
)
out.node_id["author"]                         # sampled author ids
et = ("author", "writes", "paper")
edge_index = mx.stack([out.row[et], out.col[et]])
class mlx_cluster.HeteroSamplerOutput[source]#

Result of hetero_neighbor_sample().

Variables:

  • node_id -- Global ids of the sampled nodes per node type. For each seeded node type, the first len(seed_dict[t]) entries are the seeds in the order given.

  • row -- Per edge type, local index (into node_id[src]) of each sampled edge's source node.

  • col -- Per edge type, local index (into node_id[dst]) of each sampled edge's destination node. mx.stack([row, col]) is the sampled subgraph's edge_index for that edge type.

  • edge_id -- Per edge type, offset of each sampled edge in row_dict[edge_type] (i.e. its position in CSC order).

  • num_sampled_nodes -- Per node type, [#seeds, #new at hop 1, ...].

  • num_sampled_edges -- Per edge type, [#edges at hop 1, ...].

mlx_cluster.metapath_random_walk(csr: MetaPathCSR, start: array, walk_length: int, rand: array | None = None, stream: Stream | None = None) → Tuple[array, array][source]#

Meta-path guided uniform random walks.

Step l of every walk follows edge type metapath[l % len(metapath)], choosing uniformly among the current node's neighbors of that type. If a node has no such neighbor, the walk stops and the remaining entries are -1.

Parameters:

  • csr (MetaPathCSR) -- Output of build_metapath_csr().

  • start (array) -- Start node ids, local to metapath[0][0]'s node type.

  • walk_length (int) -- Number of steps per walk. If it is longer than the meta-path, the meta-path must be cyclic (end where it starts).

  • rand (Optional[array]) -- Optional uniform [0, 1) values of shape [len(start), walk_length]. Drawn from MLX's RNG if omitted, so mx.random.seed makes walks reproducible.

  • stream (Optional[Stream]) -- Stream or device to run on (mx.cpu or mx.gpu).

Returns:

nodes is [len(start), walk_length + 1] local node ids (the type of column j is metapath_node_types(metapath, walk_length)[j]); edges is [len(start), walk_length] edge offsets within each relation's CSR.

Return type:

tuple (nodes, edges)

Example:

metapath = [
    ("author", "writes", "paper"),
    ("paper", "published_in", "venue"),
    ("venue", "publishes", "paper"),
    ("paper", "written_by", "author"),
]
csr = build_metapath_csr(edge_index_dict, metapath)
nodes, _ = metapath_random_walk(csr, mx.arange(10), walk_length=8)

See Sparse Matrix Multiplication (SpMM) for an overview, conventions and performance notes.

mlx_cluster.spmm_coo(row: array, col: array, x: array, values: array | None = None, num_rows: int | None = None, reduce: Literal['sum', 'add', 'mean', 'max', 'min'] = 'sum', *, stream=None) → array[source]#

SpMM with A given as a COO edge list (any edge order).

out[r] = reduce_{e : row[e] == r} values[e] * x[col[e]]

GPU kernel: one thread per (edge, feature) with atomic adds (max/min use integer atomics on an order-preserving encoding of the floats).

Parameters:

  • row (array) -- [num_edges] destination node of each edge.

  • col (array) -- [num_edges] source node of each edge.

  • x (array) -- [num_nodes, features] node features.

  • values (Optional[array]) -- optional [num_edges] edge weights.

  • num_rows (Optional[int]) -- number of output rows. Defaults to x.shape[0].

  • reduce (Literal['sum', 'add', 'mean', 'max', 'min']) -- how the messages values[e] * x[col[e]] arriving at a row are combined, per feature: "sum" (or "add"), "mean", "max" or "min". Rows without edges give 0 for every reduction. For "max"/"min", the gradient goes to every edge whose message equals the output (ties included), as in MLX's scatter max/min; mx.jvp is not supported for them.

Return type:

array

Returns:

[num_rows, features] array with the dtype of x.

mlx_cluster.spmm_csr(rowptr: array, col: array, x: array, values: array | None = None, reduce: Literal['sum', 'add', 'mean', 'max', 'min'] = 'sum', *, long_rows: LongRows | None = None, transpose: CSRTranspose | None = None, stream=None) → array[source]#

SpMM with A given in CSR format (see coo_to_csr()).

GPU kernel: one thread per (row, feature), no atomics, deterministic.

Parameters:

  • rowptr (array) -- [num_rows + 1] row pointer.

  • col (array) -- [num_edges] source node of each edge, in CSR order.

  • x (array) -- [num_nodes, features] node features.

  • values (Optional[array]) -- optional [num_edges] edge weights, in CSR order.

  • reduce (Literal['sum', 'add', 'mean', 'max', 'min']) -- how the messages values[e] * x[col[e]] arriving at a row are combined, per feature: "sum" (or "add"), "mean", "max" or "min". Rows without edges give 0 for every reduction. For "max"/"min", the gradient goes to every edge whose message equals the output (ties included), as in MLX's scatter max/min; mx.jvp is not supported for them.

  • long_rows (Optional[LongRows]) -- optional LongRows (CSR.long_rows from coo_to_csr()). Strongly recommended for graphs with hub nodes: without it a single thread loops over each hub's edges.

  • transpose (Optional[CSRTranspose]) -- optional CSRTranspose (CSR.transpose). With it, the gradient w.r.t. x uses the CSR kernel on the transpose (deterministic); without it, the COO kernel.

Return type:

array

Returns:

[rowptr.size - 1, features] array with the dtype of x.

mlx_cluster.coo_to_csr(row: array, col: array, num_rows: int, values: array | None = None, long_row_threshold: int | None = 256, chunk_size: int = 2048, transpose: bool = True, num_cols: int | None = None) → CSR[source]#

Converts a COO edge list into CSR (sorted by row).

This needs a sort, so compute it once per graph and reuse it.

Parameters:

  • long_row_threshold (Optional[int]) -- rows with more edges than this get the load-balanced long-row path in spmm_csr() (see LongRows). None disables it and keeps the conversion fully lazy (no host read-back), e.g. inside mx.compile.

  • chunk_size (int) -- maximum number of edges per long-row chunk.

  • transpose (bool) -- also build the transposed CSR (one more sort, ~3 extra index arrays) so the backward pass of spmm_csr() uses the CSR kernel: deterministic and atomic-free. Set False to save the memory when you only need the forward pass.

  • num_cols (Optional[int]) -- number of columns (source nodes), i.e. x.shape[0] in spmm_csr(). Defaults to num_rows (square adjacency).

Return type:

CSR

mlx_cluster.edge_scores(row: array, col: array, a: array, b: array, scale: float = 1.0, *, stream=None) → array[source]#

Multi-head dot product per edge, the attention scores of graph transformers (e.g. TransformerConv).

out[e, h] = scale * <a[row[e], h], b[col[e], h]>

Equivalent to scale * (a[row] * b[col]).sum(-1) without materialising the two [num_edges, heads, channels] gathers. Differentiable w.r.t. a and b: both gradients are computed with the SpMM kernels.

GPU kernel: one SIMD group per (edge, head), all heads in one launch.

Parameters:

  • row (array) -- [num_edges] index into a (e.g. the destination node, whose queries are in a).

  • col (array) -- [num_edges] index into b (e.g. the source node, whose keys are in b).

  • a (array) -- [num_a, heads, channels], or [num_a, channels] for one head.

  • b (array) -- [num_b, heads, channels], or [num_b, channels] for one head. num_a and num_b may differ (bipartite graphs).

  • scale (float) -- factor applied to every score, e.g. 1 / sqrt(channels).

Return type:

array

Returns:

[num_edges, heads] ([num_edges] for 2-D inputs), with the dtype of a.

class mlx_cluster.CSRTranspose[source]#

The transpose of a CSR matrix (edges grouped by source node).

Used by spmm_csr() for the backward pass A^T @ grad, so the gradient w.r.t. x also runs on the deterministic, atomic-free CSR kernel. Built by coo_to_csr() (transpose=True).

Variables:

  • rowptr -- int64 [num_cols + 1].

  • col -- int64 [num_edges] destination (original row) of each edge.

  • perm -- int64 [num_edges]; transposed edge i is CSR edge perm[i] (used to reorder edge values).

  • long_rows -- optional LongRows for high out-degree nodes.

class mlx_cluster.LongRows[source]#

Load-balancing metadata for CSR rows with many edges.

Rows with more than threshold edges are not handled by the regular one-thread-per-(row, feature) CSR kernel, where a single thread would loop over every edge of a hub node. Instead each such row is cut into chunks of at most chunk_size consecutive edges, each chunk is summed by its own GPU threadgroup, and the chunk sums are added in a fixed order (results stay deterministic). Built by coo_to_csr().

Variables:

  • rows -- int64 [L] ids of the long rows.

  • chunk_ptr -- int64 [L + 1]; long row l owns chunks chunk_ptr[l]:chunk_ptr[l + 1].

  • chunk_start -- int64 [K] first edge of each chunk.

  • chunk_end -- int64 [K] one past the last edge of each chunk.

  • threshold -- rows with more edges than this are "long".
